# 紧凑响应式布局设计

## 目标

默认 800×600 窗口内不出现页面级横向滚动，配置名称保持横向可读，常用操作清晰且完整可达。保留现有功能、配色和列表/网格视图。

## 布局

- 桌面宽度下将工作区侧栏收窄为约 150px，主内容列使用 `minmax(0, 1fr)`，所有可伸缩子项允许收缩。
- 配置区标题与工具栏分层：标题独占标题行；视图、排序和批量操作组成可换行工具行，“新建配置”保持醒目但不挤占首行。
- 搜索框占据可用宽度，浏览器筛选按钮在下一行或剩余空间内均匀排列。
- 列表卡片改为上下两区：首行放选择框、名称、浏览器和工作区摘要；次行放状态与操作。名称单行截断并显示完整标题提示，禁止逐字换行。
- 次要操作允许自然换行；按钮保持至少 36px 点击高度。网格视图继续使用卡片布局，但统一间距与操作按钮尺寸。

## 响应式规则

- 约 900px 以下启用紧凑双栏布局，以覆盖默认 800px 窗口。
- 约 680px 以下切换为单栏：工作区筛选横向换行，侧栏不再吸顶。
- 页面与主要容器设置 `min-width: 0`，只允许局部菜单或内容区域纵向滚动，不产生页面级横向滚动。

## 验证

- 在 800×600、1024×768 和窄于 680px 的视口检查列表与网格视图。
- 覆盖长配置名、多个工作区、选中批量操作和全部卡片操作。
- 运行 `npm test`；布局修改后运行 `npm run build:mac` 并打开打包应用进行视觉冒烟测试。
