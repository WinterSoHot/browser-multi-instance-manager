# v1.3.1 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce verified local macOS x64 and arm64 installers for version `1.3.1`.

**Architecture:** Use npm's manifest-aware version command to keep the package manifest and lockfile root entries synchronized. Reuse the existing Node test suite, electron-builder configuration, and macOS disk-image verifier without changing application code or dependencies.

**Tech Stack:** npm, Node.js test runner, electron-builder, macOS `hdiutil`

**Spec:** `docs/superpowers/specs/2026-08-30-v1.3.1-release-design.md`

## Global Constraints

- The release version is exactly `1.3.1`.
- Do not change source code, dependencies, workflow behavior, or release notes.
- Produce local artifacts only; do not commit the version bump, push, tag, or publish a GitHub Release.
- Build and verify both macOS x64 and arm64 DMG files.

---

### Task 1: Synchronize and verify release metadata

**Files:**
- Modify: `package.json:3`
- Modify: `package-lock.json:3`
- Modify: `package-lock.json:9`
- Test: `test/workflow.test.js`

**Interfaces:**
- Consumes: npm package metadata with current version `1.3.0`.
- Produces: package metadata whose manifest and lockfile versions are all `1.3.1`.

- [ ] **Step 1: Verify the new-version assertion initially fails**

Run:

```bash
node -e "const p=require('./package.json'); const l=require('./package-lock.json'); if (p.version !== '1.3.1' || l.version !== '1.3.1' || l.packages[''].version !== '1.3.1') process.exit(1)"
```

Expected: exit code `1` because all three values are currently `1.3.0`.

- [ ] **Step 2: Update manifest and lockfile metadata**

Run:

```bash
npm version 1.3.1 --no-git-tag-version
```

Expected: npm prints `v1.3.1`; only `package.json` and `package-lock.json` change.

- [ ] **Step 3: Verify exact version synchronization**

Run the Step 1 command again.

Expected: exit code `0`.

- [ ] **Step 4: Run repository tests and patch checks**

Run:

```bash
npm test
git diff --check
git status --short
```

Expected: 127 tests pass, the diff check is clean, and the status lists only the two version files plus this plan document.

### Task 2: Build and verify macOS artifacts

**Files:**
- Generate (ignored): `dist/Browser Multi-Instance Manager-1.3.1.dmg`
- Generate (ignored): `dist/Browser Multi-Instance Manager-1.3.1-arm64.dmg`

**Interfaces:**
- Consumes: synchronized version `1.3.1` metadata and the existing electron-builder configuration.
- Produces: validated x64 and arm64 DMG installers.

- [ ] **Step 1: Build both macOS architectures**

Run:

```bash
npm run build:mac
```

Expected: electron-builder exits `0` and creates both `1.3.1` DMG files. An unsigned-build warning is acceptable because no Developer ID is configured locally.

- [ ] **Step 2: Verify both disk images**

Run:

```bash
hdiutil verify "dist/Browser Multi-Instance Manager-1.3.1.dmg"
hdiutil verify "dist/Browser Multi-Instance Manager-1.3.1-arm64.dmg"
```

Expected: both commands exit `0` and report `VALID`.

- [ ] **Step 3: Confirm final scope and artifacts**

Run:

```bash
git diff --check
git status --short
ls -lh "dist/Browser Multi-Instance Manager-1.3.1.dmg" "dist/Browser Multi-Instance Manager-1.3.1-arm64.dmg"
```

Expected: only the two version files and this plan document are uncommitted, both DMGs exist, and no push, tag, or release has been created.
