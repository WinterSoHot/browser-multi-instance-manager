# v1.3.1 Release Design

## Goal

Package the current reliability and performance improvements as version `1.3.1` without changing application behavior.

## Scope

- Update the application version in `package.json` and the root package entries in `package-lock.json`.
- Keep source code, dependencies, workflow behavior, and release notes unchanged.
- Run the complete Node.js test suite and repository consistency checks.
- Build macOS x64 and arm64 DMG installers and verify both images with `hdiutil verify`.

## Release Boundaries

This task produces validated local artifacts only. It does not commit the version bump, push `main`, create tag `v1.3.1`, or publish a GitHub Release unless those actions are requested separately.

## Success Criteria

- Manifest and lockfile versions both equal `1.3.1`.
- `npm test` completes with zero failures.
- The macOS packaging command exits successfully.
- Both `1.3.1` DMG files pass checksum verification.
- The working tree contains only the expected version changes and this approved design document.
