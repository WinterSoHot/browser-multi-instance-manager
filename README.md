# 浏览器多实例管理器

桌面应用程序，支持同时打开多个浏览器窗口，每个窗口使用不同的用户配置文件。

## 功能特性

- 支持 Chrome、Firefox、Microsoft Edge、Zen 浏览器
- 添加/重命名/删除浏览器配置
- 工作区、收藏、四种排序与最近使用记录
- 新建空白副本，以及仅含配置元数据的导入/导出
- 一键启动浏览器并使用指定配置
- 应用重启后恢复仍在运行的浏览器状态
- 工作区和选中配置的批量启动/关闭（最多四项并发）
- 选中配置的批量工作区分配、收藏与最小元数据导出
- 自动检测常见浏览器安装位置并校验自定义路径
- 配置诊断、受控的空目录重建和打开配置文件夹
- 配置持久化存储

## 技术栈

### 使用说明

1. 点击“添加新配置”，选择浏览器类型和名称；“启动”“文件夹”“重命名”“大小”“新建空白副本”和“删除”分别用于日常管理。删除时可保留数据或移入系统废纸篓。
2. 通过左侧“全部、收藏、未分组”和自定义工作区筛选；可创建、重命名、删除工作区，为配置设置归属或收藏。删除工作区只会让其中的配置变为未分组。
3. 用排序菜单按名称、创建时间、最近使用或运行状态查看。搜索或工作区筛选后，隐藏的选择会自动取消；全选和批量操作只处理当前可见配置。

选中配置后，可通过“整理选中”统一移动工作区、收藏/取消收藏或只导出选中项。选中项导出仍只包含浏览器类型和配置名称，不包含工作区、收藏、路径、时间、进程信息或浏览数据。

4. 在自定义工作区中可一键启动或关闭可见成员。操作先取得一次强制状态快照，最多同时处理四项：启动会跳过运行中或状态未知的配置；关闭只处理运行中或可重试关闭的配置。
5. 导入采用两阶段流程：先预览可导入、重复和无效项目，再对重复项目选择“跳过”或“自动重命名”。有无效项目时不能确认导入。导出与导入都只包含浏览器类型和配置名称，不包含 Cookie、历史、凭据、工作区、收藏、路径、时间、进程信息或浏览数据。
6. 点击配置上的诊断状态可重新检测、前往浏览器设置，或在浏览器路径有效且配置明确停止时重新创建缺失的空目录。不会覆盖既有目录；状态未知或正在运行时不能重建、移动或删除目录。

重启恢复后如显示“状态未知”，请先“重试”。仍无法确认时可在警告确认后“仅清除记录”；这只清除管理器跟踪数据，不会终止对应进程。请在确认原浏览器退出前不要再次启动同一配置。

### 系统托盘与退出

- 默认关闭窗口会最小化到系统托盘；可在“设置”中关闭“关闭窗口时最小化到系统托盘”。
- 双击托盘图标或选择“打开主界面”会恢复窗口。托盘可按工作区启动收藏；启动前只读取一次强制状态快照，跳过运行中和状态未知的配置，最多四项并发。
- 选择托盘“退出”只退出管理器，绝不关闭浏览器。只要存在运行中或状态未知的配置，都会先显示明确警告。
- Windows/Linux 关闭到托盘被禁用时，关闭最后窗口也会经过同一退出检查；macOS 保持平台惯例，仅关闭窗口。

### 版本检查与下载页

- 默认会在首次主界面加载后检查 GitHub Releases；可在“设置”中关闭“启动后检查更新”。设置页显示当前版本，并可选择“立即检查更新”。
- 成功结果会按当前应用版本缓存 24 小时。手动“立即检查更新”会绕过时间缓存，但若已有检查进行中会共享同一请求，不会重复联网。
- 首页仅在发现较新版本时显示提示；关闭提示后，同一版本在本次运行期间不再显示，发现新版本时会重新提示。当前、缓存结果、可用更新和失败都会显示稳定的中文状态。
- 只会打开严格校验的 `https://github.com/WinterSoHot/browser-multi-instance-manager/releases/tag/v<版本号>` 下载页。应用不会自动下载或安装更新。
- 检查失败不会阻塞应用，不缓存失败结果，也不会显示或泄露 GitHub 响应内容、路径或原始错误。

## 项目结构

```
.
├── main.js                       # Electron 主进程和 IPC
├── preload.js                    # 安全的渲染进程桥接
├── lib/
│   ├── app-store.js              # 应用数据存储、默认值和版本迁移
│   ├── profile-service.js        # 配置生命周期、目录操作和元数据导入导出
│   ├── ipc-handlers.js           # 主进程 IPC 注册和输入校验
│   └── ...                       # 路径、进程管理及其他基础模块
├── renderer/
│   ├── profile-state.js          # 配置列表、筛选、排序和选择状态
│   ├── index.js                  # 主界面编排和渲染
│   └── ...                       # 设置页面及样式
└── test/                         # Node.js 单元测试
```
