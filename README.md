# 浏览器多实例管理器

桌面应用程序，支持同时打开多个浏览器窗口，每个窗口使用不同的用户配置文件。

## 功能特性

- 支持 Chrome、Firefox、Microsoft Edge、Zen 浏览器
- 添加/重命名/删除浏览器配置
- 新建空白副本，导入/导出不含浏览数据的配置元数据
- 一键启动浏览器并使用指定配置
- 应用重启后恢复仍在运行的浏览器状态
- 批量启动/关闭、搜索筛选和可见项全选
- 自动检测常见浏览器安装位置并校验自定义路径
- 打开配置文件夹
- 配置持久化存储

## 技术栈

- Electron
- electron-store

## 使用方法

### 安装依赖

```bash
npm install
```

### 启动应用

```bash
npm start
```

### 运行测试

```bash
npm test
```

测试覆盖配置名与路径校验、浏览器进程跟踪以及批量操作结果汇总。

### 使用说明

1. 点击"添加新配置"，选择浏览器类型并输入配置名称
2. 点击"启动"按钮，使用对应配置打开浏览器
3. 点击"文件夹"可在 Finder 中查看配置数据
4. 点击"重命名"修改配置名称
5. 点击“大小”按需统计配置目录，点击“新建空白副本”创建不含原浏览数据的隔离配置
6. 点击“删除”从列表移除配置；可选择保留数据或移入系统废纸篓
7. 使用“导入/导出”迁移配置名称和浏览器类型；不会导出 Cookie、历史记录或凭据

如果重启恢复后显示“状态未知”，先点击“重试”。仍无法确认时，可点击“仅清除记录”；确认后只清除管理器记录，不会终止对应进程。原浏览器可能仍在运行，请勿在确认其退出前再次启动同一配置。

## 项目结构

```
.
├── main.js                       # Electron 主进程和 IPC
├── preload.js                    # 安全的渲染进程桥接
├── lib/
│   ├── app-store.js              # 应用数据存储、默认值和版本迁移
│   ├── profile-service.js        # 配置生命周期、目录操作和元数据导入导出
│   ├── ipc-handlers.js           # 主进程 IPC 注册和输入校验
│   └── ...                       # 路径、进程管理及其他基础模块
├── renderer/
│   ├── profile-state.js          # 配置列表、筛选、排序和选择状态
│   ├── index.js                  # 主界面编排和渲染
│   └── ...                       # 设置页面及样式
└── test/                         # Node.js 单元测试
```

## 构建安装包

### 构建 macOS DMG

```bash
npm run build:mac
```

### 构建 Windows EXE

```bash
npm run build:win
```

### 构建所有平台

```bash
npm run build:all
```

构建完成后，安装包位于 `dist/` 目录下。

- macOS
